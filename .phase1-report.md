## 5. Recommendations for Phase 2

1. **Unhandled promises in sandbox/iframe code** — Decide on a policy for `Webxdc.tsx` injected script promises and apply consistent `.catch` logging.
2. **React hook dependency suppressions** — Audit the ~40 `eslint-disable-next-line react-hooks/exhaustive-deps` comments, especially in `useCashuWallet.ts` (5 suppressions) and the Pets onboarding/companion hooks, for stale-closure bugs.
3. **Cashu wallet deep-dive** — `src/hooks/useCashuWallet.ts` is large (2,339 lines) and newly added. Review state updates after unmount, proof recovery loops, and the `freedomid_restore_attempted` flag logic.
4. **Pets migration/rename regressions** — The Blobbi→Pets rename touched hundreds of files. Spot-check remaining `blobbi` string references and verify all import paths resolve.
5. **Stale `setTimeout` IDs** — Sweep components that set copied-state timers (`GitRepoCard`, `NoteMoreMenu`, `OnchainZapContent`, `PullRequestCard`, `ZapDialog`, etc.) and guard `setState` with a mounted ref to avoid React warnings.
6. **Build verification** — Run `npm test` (includes `vite build`) end-to-end to catch any build-time only regressions introduced by the uncommitted feature work.
