# robots.txt — 2140.wtf
#
# Two questions, two answers — the same split every BAO host now carries:
#
#   1. "May I copy this whole site to train a model?"        -> NO.
#   2. "May I fetch /llms.txt because someone just asked me   -> YES.
#       a question about 2140.wtf?"
#
# This host serves one page — the client shell — plus the static assets and the
# agent documents beside it. The content people actually care about (notes,
# rooms, markets, wallet state) lives on Nostr relays and is fetched at runtime,
# so there is no corpus here to train on and nothing to crawl. What IS worth
# fetching on demand is the written surface: the agent guide, the chat protocol
# and the machine manifest. Those are allowed; the app shell is not, and is
# never served to a retrieval agent.
#
# RFC 9309 §2.2.2: the LONGEST matching path wins and `Allow` beats `Disallow`
# at equal length, so each group can end in `Disallow: /` and still hand over
# the paths below. The `$` on each file path is load-bearing: without it a
# robots.txt path is a PREFIX match and `Allow: /llms.txt` would also allow
# /llms.txt.bak.
#
# Non-conformant parsers (Python's `urllib.robotparser` is one: first-match
# prefix, no `$`, no longest-match) read these groups as a plain `Disallow: /`,
# which is what they saw before this file changed.
